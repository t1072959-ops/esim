系統怎麼串起來

前端商店只負責選方案、收款；下單當下由後端呼叫批發商 API，取得 QR Code 後回傳給客人 —— API Key 全程不落地到瀏覽器。

01

客人下單

選擇國家/流量方案，填 Email，導向金流（ECPay / NewebPay）付款。

02

金流 Webhook

付款成功後，金流回呼你的後端，帶上訂單編號與方案代碼。

03

批發商 API 下單

後端用你的 Access Code + 密鑰呼叫 eSIM Access / eSIM Go，取得 QR Code (LPA 字串)。

04

出票給客人

把 QR Code 寫回訂單，Email 或網頁直接顯示，客人掃描即可安裝。
